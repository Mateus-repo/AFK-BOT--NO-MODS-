🤖 AFK Bot for Minecraft Servers

Complete Installation and Usage Guide

📋 Description

This is an AFK bot for Minecraft, built with Mineflayer, that enables various operations via terminal commands. The bot works on any Minecraft server, whether cracked or premium, offers multiple real-time configuration commands, and supports multiple languages.

⚙️ Prerequisites

Required Software:

  • Node.js (version 14 or higher)
  • NPM (to install dependencies)
  • C++ Compiler (to build the C++ launcher, optional)

Installing Dependencies

npm install mineflayer mineflayer-pathfinder minecraft-data express

🚀 Installation

1. Obtain the Project

Download or clone the bot’s files locally without referencing any specific platform (e.g., GitHub).

2. Install Dependencies

npm install

3. Configure settings.json

{ "server": { "ip": "play.example.com", "port": 25565, "version": "1.20.4" }, "bot-account": { "type": "mojang", "username": "YourBotNameHere", "password": "" }, "language": "pt-pt", "maxRam": "1G" }

💡 Important Settings:

server: Minecraft server settings (IP, port, version)
bot-account: account type (“mojang” or “microsoft”), username, and password
language: initial language (“pt-pt” or “eng”)
maxRam: maximum memory for the bot

🌐 Languages

Language files are located in:

  • lang/pt-pt.txt – Portuguese
  • lang/eng.txt – English

Each line follows the format key=value. To add phrases or adjust translations, edit the corresponding file.

⌨️ Available Commands

All commands must be prefixed with / in the terminal:

/stop
Stops the bot and exits the script
/stop
/server
Displays current server information
/server
/changeserver
Changes the server. Default port: 25565
/changeserver example.com:25570
/changename
Changes the bot’s username
/changename NewBotName
/chat
Sends a message in the game chat
/chat Hello everyone!
/pos
Displays the bot’s current position (x, y, z)
/pos
/ping
Displays the bot’s current ping (latency)
/ping
/ram
Restarts the bot applying the memory configuration
/ram
/version
Changes the server version and reconnects
/version 1.20.4
/lang
Changes the bot’s language
/lang pt-pt
/changetype
Changes the account type (mojang/microsoft)
/changetype microsoft
/typeinfo
Displays the current account type
/typeinfo
/reload
Clears the console and restarts the script
/reload
/restart
Alias for /reload
/restart
/help
Displays all available commands
/help

🔧 C++ Launcher

The run.cpp file executes index.js using Node.js. To compile and use:

g++ run.cpp -o run.exe ./run.exe

💡 Usage Example

1. Start the Bot

run.exe # or directly node index.js

2. Using Commands

> /server Current server information: play.example.com:25565 (v1.20.4) > /changetype microsoft Changing the bot’s account type to microsoft Please enter the Microsoft account email:
