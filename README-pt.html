🤖 Bot AFK para servidores de mine

Guia Completo de Instalação e Uso

📋 Descrição

Este é um bot AFK para Minecraft, construído com Mineflayer, que permite várias operações via comandos no terminal. O bot funciona em qualquer servidor de mine, seja pirata (cracked) ou original (premium), oferece múltiplos comandos de configuração em tempo real e suporte multilíngue.

⚙️ Pré-requisitos

Software Necessário:

  • Node.js (versão 14 ou superior)
  • NPM (para instalar dependências)
  • Compilador C++ (para construir o executor em C++, opcional)

Instalando Dependências

npm install mineflayer mineflayer-pathfinder minecraft-data express

🚀 Instalação

1. Obtenha o Projeto

Faça o download ou clone localmente os arquivos do bot sem referência a nenhuma plataforma específica (por exemplo, GitHub).

2. Instale as Dependências

npm install

3. Configure o settings.json

{ "server": { "ip": "play.exemplo.com", "port": 25565, "version": "1.20.4" }, "bot-account": { "type": "mojang", "username": "NomeDoBotAqui", "password": "" }, "language": "pt-pt", "maxRam": "1G" }

💡 Configurações Importantes:

server: configurações do servidor de Minecraft (IP, porta, versão)
bot-account: tipo de conta (“mojang” ou “microsoft”), nome de usuário e senha
language: idioma inicial (“pt-pt” ou “eng”)
maxRam: memória máxima para o bot

🌐 Idiomas

Os arquivos de idioma estão localizados em:

  • lang/pt-pt.txt – Português
  • lang/eng.txt – Inglês

Cada linha segue o formato chave=valor. Para adicionar frases ou ajustar traduções, edite o arquivo correspondente.

⌨️ Comandos Disponíveis

Todos os comandos devem ser prefixados com / no terminal:

/stop
Para o bot e encerra o script
/stop
/server
Exibe as informações atuais do servidor
/server
/changeserver
Altera o servidor. Porta padrão: 25565
/changeserver exemplo.com:25570
/changename
Altera o nome de usuário do bot
/changename NovoNomeDoBot
/chat
Envia uma mensagem no chat do jogo
/chat Olá a todos!
/pos
Exibe a posição atual do bot (x, y, z)
/pos
/ping
Exibe o ping (latência) atual do bot
/ping
/ram
Reinicia o bot aplicando a configuração de memória
/ram
/version
Altera a versão do servidor e reconecta
/version 1.20.4
/lang
Altera o idioma do bot
/lang pt-pt
/changetype
Altera o tipo de conta (mojang/microsoft)
/changetype microsoft
/typeinfo
Exibe o tipo de conta atual
/typeinfo
/reload
Limpa o console e reinicia o script
/reload
/restart
Alias para /reload
/restart
/help
Exibe todos os comandos disponíveis
/help

🔧 Executor em C++

O arquivo run.cpp executa index.js usando o Node.js. Para compilar e usar:

g++ run.cpp -o run.exe ./run.exe

💡 Exemplo de Uso

1. Inicie o Bot

run.exe # ou diretamente node index.js

2. Usando Comandos

> /server Informações atuais do servidor: play.exemplo.com:25565 (v1.20.4) > /changetype microsoft Alterando o tipo de conta do bot para microsoft Por favor, insira o e-mail da conta Microsoft:
